How to install Juxta
====================

Requires macOS 15 Sequoia or later. Runs on Apple Silicon and Intel Macs.

Juxta isn't notarized by Apple, so on a new Mac macOS blocks it the first
time. Pick ONE of the two ways below, and use the Terminal fixes if it fails.


OPTION A: Installer package (Juxta-x.x.pkg)
-------------------------------------------
1. Double-click Juxta-x.x.pkg.
2. If macOS says it "can't be opened" or "could not verify" it: click Done,
   open System Settings > Privacy & Security, scroll to Security and click
   "Open Anyway" next to Juxta-x.x.pkg. Enter your password.
3. Follow the installer. Juxta is installed in Applications and opens itself.


OPTION B: Disk image (Juxta-x.x.dmg)
------------------------------------
1. Open the .dmg and drag Juxta onto the Applications folder.
2. Open Juxta from Applications. If macOS blocks it, click Done (don't move
   it to the Bin), then System Settings > Privacy & Security > "Open Anyway".


IF IT STILL FAILS: Terminal commands
------------------------------------
Open Terminal (Applications > Utilities > Terminal), paste a command, press
Return and type your Mac password when asked (nothing shows as you type).

1. The installer package won't open. Install it from Terminal instead
   (change the path if the file isn't in Downloads):

       sudo installer -pkg ~/Downloads/Juxta-*.pkg -target /

2. Juxta is installed but won't open, or macOS says it is "damaged":

       sudo xattr -cr /Applications/Juxta.app && open /Applications/Juxta.app

3. "Open Anyway" doesn't appear, or the .pkg / .dmg itself is blocked:

       xattr -c ~/Downloads/Juxta-*

   then double-click the file again.

4. Juxta can't read files or folders on your Desktop, in Documents or
   Downloads, or on an external drive (you clicked "Don't Allow" when macOS
   asked):

       tccutil reset All app.juxta.Juxta

   then quit and reopen Juxta and click Allow when it asks again
   (or turn Juxta on in System Settings > Privacy & Security >
   Files & Folders).

5. Check the Mac is new enough (must say 15 or higher):

       sw_vers -productVersion


AFTER INSTALLING
----------------
Juxta opens on its home screen. Pick a session type, or just drag two files
or folders onto the window: folders open a folder compare, images a picture
compare, CSV/TSV a table compare, binaries a hex compare, and anything else
a text compare. Three files open a 3-way merge. Press Option-Command-Down /
Up to jump between differences, and Command-, for Settings (font, tab width,
ignore rules and, on macOS 26, the Liquid Glass theme).

Juxta keeps no documents of its own; it only remembers recent files,
folders, sessions and settings in ~/Library/Preferences/app.juxta.Juxta.plist.

To uninstall: quit Juxta, then run

       rm -rf /Applications/Juxta.app ~/Library/Preferences/app.juxta.Juxta.plist
